## The four tiers, and what "stale" means in each

| Tier | Lives in | Who edits | Freshness signal |
|---|---|---|---|
| **Canon** | `config/canon/*.md` | the operator; the maintainer proposes | `last_verified` + `ttl_days` frontmatter. Past TTL = **SUSPECT**; agents say so rather than act silently. |
| **Routine rules** | `routines/rules/<routine>.md` | the operator; the maintainer proposes | same frontmatter; the routine file wins on mechanics if the two disagree |
| **GENERATED** | `state/now/` | nobody. `scripts/generate_*.py`, run by the daily guard | `generated_at` line; `--check` exits 1 on drift |
| **Index** | this file | the operator, when a row moves | none needed; it carries no rules |
